## 2024-05-18 - [Path Traversal in shutil.copytree]
**Vulnerability:** A path traversal (arbitrary file read / exfiltration) vulnerability existed because `shutil.copytree` was called without `symlinks=True`.
**Learning:** By default, Python's `shutil.copytree` follows symlinks. If an attacker controls the contents of the source directory and places a symlink pointing to a sensitive file (like `/etc/passwd` or an SSH key) in the directory tree being copied, `copytree` will follow the symlink and copy the *contents* of the sensitive file into the destination directory. If this destination directory is later accessible to the user (e.g. through the application), the attacker has successfully achieved arbitrary file read.
**Prevention:** Whenever using `shutil.copytree` on directories that might contain untrusted or user-controlled files/symlinks, ALWAYS explicitly set `symlinks=True` (and usually `ignore_dangling_symlinks=True`). This ensures that the symlink itself is copied, rather than the file it points to being read and copied.
