## 2024-05-18 - Prevent TOCTOU symlink hijack in path.chmod()
**Vulnerability:** A Time-of-Check to Time-of-Use (TOCTOU) vulnerability in `_secure_mkdir` where `path.chmod(0o700)` is called on a directory after it is created. An attacker could replace the newly created directory with a symlink before `path.chmod()` is called, causing the permissions of the symlink's target to be modified instead of the directory itself.
**Learning:** `pathlib.Path.chmod` and `os.chmod` follow symlinks by default on POSIX systems. `pathlib.Path.chmod` doesn't directly support `follow_symlinks=False`. This makes naive `mkdir()` followed by `chmod()` vulnerable to symlink replacement attacks.
**Prevention:** When enforcing secure directory permissions via `path.mkdir(exist_ok=True)` and subsequent `path.chmod()`, verify the path is not a symlink first (e.g., `if path.exists() and path.is_symlink(): raise OSError(...)`). On POSIX systems, `path.chmod()` follows symlinks, which can be exploited to alter the permissions of arbitrary system directories via symlink hijacking.
