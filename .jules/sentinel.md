## 2026-09-01 - [Fix TOCTOU vulnerability in file size logging logic]
**Vulnerability:** In `session_linker.py`, the `_log` function checked the error log file size using `ERR_LOG.exists() and not ERR_LOG.is_symlink() and ERR_LOG.stat().st_size > 5 * 1024 * 1024`. This was vulnerable to a TOCTOU race condition because `path.exists()` and `path.stat()` implicitly follow symlinks, which means if an attacker swapped the log file for a symlink pointing to an arbitrary file between the `exists()` check and the `is_symlink()` check, the application could be made to fail (DoS) via an `OSError`, or in this case perform unwanted operations like removing or renaming the symlink's target file.
**Learning:** Checking for `exists()` or `is_file()` before checking `is_symlink()` is an anti-pattern as they implicitly resolve symlinks. Also, calling `path.stat()` on an untrusted path might raise `OSError` (FileNotFoundError) if it points to a broken symlink.
**Prevention:** Always check `.is_symlink()` FIRST before checking `.exists()` or `.is_dir()`. When checking the size of untrusted files for DoS prevention, use `path.stat(follow_symlinks=False).st_size` or wrap the operation in a try-except `OSError` block.
