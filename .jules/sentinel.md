## 2026-08-11 - [Use os.scandir for Efficient Secure Directory Traversal]
**Vulnerability:** Redundant `stat()` syscalls when traversing directories securely (checking for symlinks and checking if dir/file). Path traversal via unbounded symlinks if not explicitly checked during traversal.
**Learning:** `pathlib.Path.iterdir()` paired with `.is_symlink()`, `.is_dir()`, or `.is_file()` causes multiple separate `stat()` calls per file, which is an inefficient approach (O(N) I/O bottleneck) that can be abused for DoS if directories have many files. Additionally, `.is_dir()` and `.is_file()` implicitly follow symlinks, introducing path traversal risks if `.is_symlink()` isn't checked first.
**Prevention:** Use `os.scandir()` which yields `os.DirEntry` objects. These cache file attributes, making `entry.is_symlink()`, `entry.is_dir(follow_symlinks=False)`, and `entry.is_file(follow_symlinks=False)` much more efficient and safer by preventing excessive disk I/O and unintended symlink traversal.
