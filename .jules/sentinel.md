## 2024-05-15 - [CRITICAL] Fix TOCTOU vulnerability in shutil.copytree
**Vulnerability:** Python's `shutil.copytree` uses `shutil.copy2` by default as the underlying file copy function. `shutil.copy2` contains a Time-of-Check to Time-of-Use (TOCTOU) vulnerability where the destination file could be replaced by a symlink after the initial checks but before the actual file operations are performed, potentially leading to arbitrary file overwrite.
**Learning:** This repo performs secure directory cloning which should not overwrite unintended files. A secure copy function must be used to perform operations atomically against the destination. However, passing this to `shutil.copytree` via `copy_function=_secure_copy` will invoke the custom copy function using `str` arguments under the hood in standard library implementations, which can crash if the custom copy function assumes it will receive `pathlib.Path` objects.
**Prevention:** Provide a custom secure copy function to `shutil.copytree` using `copy_function=`, and ensure the custom function explicitly accepts and handles `str` arguments correctly, normally by coercing them to `pathlib.Path` inside the function, while continuing to perform safe operations using `os.open` and `os.O_NOFOLLOW` checks on the destination file.
