## 2025-02-14 - Prevent Path Traversal via symlinks in scan_sessions
**Vulnerability:** The functions `scan_sessions` and `scan_cowork_sessions` were previously using `.exists()` on dynamic directories (`sessions_dir` and `cowork_sessions_dir`) and directly passing them into `os.scandir()`. Because `pathlib.Path.exists()`, `.is_dir()`, and `.is_file()` implicitly follow symlinks, a malicious symlink named `claude-code-sessions` could trick `os.scandir` into traversing an arbitrary external directory (path traversal).
**Learning:** `os.scandir()` traverses symlinked directories natively. When evaluating user-supplied or modifiable directory structures to scan, calling `path.is_dir()` or `path.exists()` is not sufficient since they implicitly follow symlinks. We must explicitly check `.is_symlink()` first to prevent `os.scandir` from reading outside the intended scope.
**Prevention:** To prevent path traversal vulnerabilities when validating or iterating directories, always evaluate `.is_symlink()` FIRST before checking `.is_dir()` or `.is_file()` (e.g., `if path.is_symlink() or not path.is_dir(): continue`) before passing the path to `os.scandir()`.
