## 2025-02-14 - Fix Path Traversal via Symlink Manipulation in shutil Operations
**Vulnerability:** Lack of explicit symlink validation before executing file and directory modification commands (`shutil.rmtree`, `shutil.copytree`, index parsing/backups) in `link_cowork_session_to_account`, `remove_session_from_account`, and `link_session_to_account`.
**Learning:** `shutil.copytree` and `shutil.rmtree` typically follow symlinks or treat them dynamically depending on kwargs, leading to potential path traversal and arbitrary file deletion/modification if user-controlled paths or pre-existing files are maliciously symlinked. Even if other layers of an application ensure files shouldn't be symlinks initially, attackers can exploit Time-of-Check-to-Time-of-Use (TOCTOU) windows or directly tamper with index and session directories.
**Prevention:** Always explicitly check for `.is_symlink()` on critical paths before modifying, copying, or backing up directories and files, particularly when invoking Python `shutil` library operations.
