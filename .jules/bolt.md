## 2024-05-30 - [Optimize JSON Loading in Directory Scans]
**Learning:** During large directory scans loading many small JSON files (like session metadata), using `json.loads(Path.read_text())` is significantly slower than using `json.load()` directly with a file object opened in binary mode `open("rb")`. This is due to the overhead of reading the entire file into a string (with decoding) before passing it to the JSON parser, whereas `json.load()` with a binary file handles reading and decoding more efficiently in chunks or at the C level.
**Action:** When reading many JSON files from disk, especially in loops scanning directories, prefer `with open(path, "rb") as f: json.load(f)` over `json.loads(Path(path).read_text())` to avoid unnecessary string allocations and decoding overhead.
