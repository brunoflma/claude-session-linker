## 2024-06-25 - Prevent O(N) stat syscalls when verifying companion directories in a scan loop
**Learning:** When looping over `os.scandir` entries to process files that have a companion directory (e.g., `local_<uuid>.json` and `local_<uuid>/`), calling `path.is_symlink()` and `path.is_dir()` repeatedly inside the loop for each companion directory creates a significant O(N) performance bottleneck due to redundant disk I/O syscalls.
**Action:** Instead of verifying companion directories with `stat` per file, collect all valid directory names (`entry.name`) in a single pass of `os.scandir` into a set (by checking `entry.is_dir()`). Then, process the files and use a fast memory lookup (`stem in valid_data_dirs`) to verify the existence of the companion directory without any additional disk operations.
