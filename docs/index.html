05 / ENTENDA O ALCANCE

Dados locais.
Decisões conscientes.

Backups antes de alterar

Em Code, o backup cobre os índices que serão alterados. Em Cowork, cobre o workspace de destino. Os arquivos ficam em .app/backups.

Operações no computador

Vincular, comparar e remover usam os dados locais. O setup acessa a internet para obter dependências; as operações de sessão não enviam conversas a um servidor do Linker.

Compatibilidade que pode mudar

O armazenamento do Claude Desktop não é uma API pública. Mudanças entre versões podem afetar o aplicativo. Confira os guias e a cópia selecionada antes de operar.

ANTES DO PRIMEIRO VÍNCULO

O que vale
saber primeiro.

Funciona entre computadores diferentes?

O Linker trabalha com contas e arquivos já presentes no mesmo computador. Ele não transfere sessões entre máquinas e não oferece sincronização na nuvem.

O vínculo mantém as cópias sincronizadas?

Em Code, o novo vínculo clona o transcript para continuação independente. Em Cowork, o índice e a pasta são copiados. O aplicativo não faz uma fusão automática de conversas que divergiram.

Por que preciso fechar o Claude Desktop?

Vincular e remover alteram arquivos locais usados pelo aplicativo. Encerre o Claude completamente antes dessas operações e reabra depois na conta de destino para conferir a barra lateral.

Minha conta de destino não aparece

Use essa conta no Claude Desktop do mesmo computador e abra Code ou Cowork pelo menos uma vez. Em seguida, feche o Claude e atualize a lista no Linker. Confira também o perfil escolhido no guia do seu sistema.

Qual cópia devo escolher quando há divergência?

Use a comparação para avaliar as informações disponíveis. Mais mensagens ou atividade recente são sinais para análise; não garantem que aquela seja a versão desejada. Não há mesclagem automática.

O projeto é oficial da Anthropic?

O Claude Session Linker é um projeto independente, mantido por Bruno Ferreira. O Claude Desktop e suas marcas pertencem à Anthropic.

Como relatar um problema?

Informe o sistema, a versão do Linker, Code ou Cowork e os passos que levaram ao problema. Use um exemplo fictício. Não anexe conversas, backups, credenciais ou identificadores de contas à issue.
