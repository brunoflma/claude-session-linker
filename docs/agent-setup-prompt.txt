Quero instalar o Claude Session Linker e entender como usar no meu computador. Prepare o aplicativo com as ferramentas e permissões disponíveis, sem alterar conversas reais automaticamente.

Repositório oficial: https://github.com/brunoflma/claude-session-linker
Página: https://brunoflma.github.io/claude-session-linker/

1. Confira meu sistema operacional, se o Claude Desktop está instalado e se já existe uma cópia do Linker. Preserve essa cópia e seus dados. Leia o README e o guia correspondente ao meu sistema na versão que será instalada: GUIA-WINDOWS.md ou GUIA-MACOS.md. Registre a tag e o commit da release.
2. Abra a última release estável do repositório oficial e baixe o pacote de Windows ou macOS correspondente ao meu sistema. Confira o hash com SHA256SUMS.txt e a origem em RELEASE.json. Extraia em uma pasta nova e permanente. Não substitua uma instalação existente nem crie uma nova release.
3. Confira Python 3.10 ou superior. No Windows, o setup é 00 - Setup Claude Session Linker.vbs e o iniciador é Claude Session Linker.vbs. No macOS, use 00 - Setup Claude Session Linker.command e Claude Session Linker.command; confira também tkinter conforme o guia. Não instale Node.js, banco de dados ou servidor para esse aplicativo.
4. O setup instala customtkinter, darkdetect e pillow em .app/venv e precisa de internet. No macOS, pode precisar do Homebrew para python-tk. Explique qualquer pré-requisito ausente antes de instalá-lo, respeite as permissões das suas ferramentas e os avisos do sistema. Não desative proteções, não use privilégios de administrador para contornar erros e não apague um ambiente anterior por conta própria.
5. Execute o setup no escopo confirmado e confira o resultado. Se precisar diagnosticar uma falha, consulte apenas o necessário nos logs da instalação, sem copiar caminhos pessoais ou conteúdo sensível para serviços externos. Deixe-me concluir diálogos ou etapas que dependam da minha interação.
6. Explique que cada conta precisa ter sido usada no Claude Desktop nesse computador e que Code ou Cowork deve ter sido aberto pelo menos uma vez. Não troque minhas contas nem leia transcripts, credenciais, registros de sessões ou rótulos de contas sem necessidade e autorização explícita.
7. Antes de qualquer vínculo ou remoção, o Claude Desktop deve estar completamente fechado. Oriente a saída pela bandeja no Windows ou Cmd+Q no macOS. Não force o encerramento com trabalho aberto; deixe-me salvar e encerrar.
8. Sua tarefa inicial termina na instalação e na orientação de uso. Não escolha uma conversa ou conta por mim. Para vincular ou remover uma sessão real, exija uma solicitação específica com sessão, conta de origem, conta de destino e operação. Confira o backup e a seleção antes da confirmação. Não execute um teste destrutivo com conversas reais.
9. Esclareça as diferenças: Code copia o índice e clona o transcript para continuação independente; Cowork copia o índice e a pasta local. Remover Code apaga o índice daquela conta; remover Cowork apaga o índice e a pasta correspondente. A comparação não mescla conversas divergentes. O Linker funciona com dados locais no mesmo computador e não é uma ferramenta de sincronização entre computadores.
10. Informe onde o aplicativo ficou, como abrir novamente, o que foi realmente verificado e o que depende de mim. Se não puder executar o setup ou abrir a interface, diga exatamente a etapa pendente. Não afirme que instalou, abriu ou validou algo que não executou. Não publique logs, backups, transcripts, credenciais ou identificadores de contas.

Ao final, me entregue um resumo curto da instalação e os próximos passos para eu escolher com segurança a primeira operação no aplicativo.
