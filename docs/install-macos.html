01 / ANTES DE COMEÇAR

Confira o que você precisa.

  • Claude Desktop instalado no computador em que você vai usar a ferramenta.
  • Contas já usadas nesse computador. Para vincular entre contas, a origem e o destino precisam ter seus dados locais preparados.
  • Python 3.10 ou superior com tkinter. Quando o Python encontrado não inclui tkinter, o setup pode precisar do Homebrew e da fórmula python-tk correspondente.
  • Acesso à internet para o primeiro setup. As operações de sessão depois usam os dados locais.
ANTES DE CONTINUARVocê está usando o guia de macOS e tem uma pasta gravável pelo seu usuário para guardar o projeto.
02 / NO SEU COMPUTADOR

Baixe e extraia o projeto inteiro.

  1. Abra a última release estável e escolha o pacote de macOS, ou use o download direto abaixo.
  2. Extraia o arquivo em uma pasta permanente. Não execute de dentro do visualizador de ZIP.
  3. Mantenha os iniciadores junto da pasta .app. Ela contém o código e os arquivos necessários para o setup.
Baixar para macOS ↓
O QUE VOCÊ DEVE ENCONTRARO arquivo 00 - Setup Claude Session Linker.command, o iniciador Claude Session Linker.command e a pasta .app no mesmo local. No macOS, pastas que começam com ponto podem ficar ocultas no Finder.
03 / INSTALAÇÃO LOCAL

Execute o setup uma vez.

  1. Use o botão direito em 00 - Setup Claude Session Linker.command e escolha Abrir.
  2. Acompanhe a configuração no Terminal. O primeiro setup usa internet para instalar dependências e pode precisar do Homebrew para disponibilizar o tkinter.
  3. Quando terminar, pressione Enter para abrir ou use Claude Session Linker.command.

O setup cria .app/venv e instala customtkinter, darkdetect e pillow. O resultado da configuração fica em .app/logs/setup-result.txt.

O macOS bloqueou o arquivo ou o .command não abre

O projeto usa scripts locais, sem assinatura ou notarização como aplicativo macOS. Confira a origem do download. Use botão direito → Abrir; se o macOS solicitar uma autorização adicional, revise o aviso nas configurações de Privacidade e Segurança.

Se o arquivo perdeu a permissão de execução, abra o Terminal na pasta extraída e use:

PERMISSÕES DOS INICIADORES
chmod +x "00 - Setup Claude Session Linker.command" "Claude Session Linker.command" ".app/setup.sh"

Depois, abra novamente o setup. Não use sudo para contornar falhas de permissão na pasta do projeto.

ANTES DE CONTINUARO setup terminou sem erro e o Linker consegue abrir. A instalação prepara a ferramenta; você ainda vai escolher as contas e as sessões.
04 / NO CLAUDE DESKTOP

Prepare cada conta e feche o Claude.

  1. Abra o Claude Desktop e entre em cada conta que pretende usar.
  2. Em cada uma, abra a aba Code ou Cowork pelo menos uma vez para criar os dados correspondentes.
  3. Salve o que estiver em andamento e encerre completamente o Claude antes de vincular ou remover sessões.
Como encerrar no macOSNo macOS, use Claude → Encerrar ou Cmd+Q. Fechar apenas a janela não encerra o aplicativo.
ANTES DE CONTINUARA origem e o destino foram usados nesse computador e o Claude Desktop está completamente fechado.
05 / NO SESSION LINKER

Escolha a sessão e o destino.

  1. Abra Claude Session Linker.command.
  2. Escolha Code ou Cowork e localize a sessão na conta de origem.
  3. Use Vincular conta e selecione a conta de destino.
  4. Confira a sessão e a conta escolhidas antes de confirmar. O aplicativo cria um backup antes da alteração.
  5. Reabra o Claude Desktop na conta de destino e confira a barra lateral.
TipoO que o vínculo faz
CodeCopia o índice e clona o transcript local. Cada conta pode continuar de forma independente.
CoworkCopia o índice e a pasta local da conversa para o workspace de destino.
COMO CONFERIRA sessão aparece na conta de destino depois de reabrir o Claude. O vínculo não mantém as cópias sincronizadas automaticamente.
06 / ESCOLHA COM CONTEXTO

Compare antes de decidir.

Use Comparar para consultar a quantidade de mensagens e a atividade disponível nos arquivos locais. Mais mensagens não garantem que aquela seja a continuação desejada. As cópias podem ter seguido caminhos diferentes.

Se quiser remover de uma conta

Feche completamente o Claude Desktop, escolha a conta e a sessão no Linker e confira a operação. A remoção tem efeitos diferentes conforme o tipo:

TipoO que é removidoBackup prévio
CodeO índice da conta escolhida. O transcript não é apagado automaticamente.Pasta de índices que será alterada.
CoworkO índice e a pasta local correspondente da conta escolhida.Workspace que será alterado.

O aplicativo não faz uma fusão automática de conversas divergentes. Use exemplos sem informações importantes para se familiarizar com o fluxo.

07 / MANTENHA A POSSIBILIDADE DE CONFERIR

Saiba onde ficam os backups.

Os backups ficam em .app/backups dentro da pasta da ferramenta. Em Code, eles cobrem os índices. Em Cowork, cobrem o workspace que será alterado. O backup de índices não equivale a um backup completo de todos os transcripts.

Ao atualizar o aplicativo

  1. Baixe o projeto e extraia em uma pasta nova.
  2. Execute o setup dessa nova cópia.
  3. Se precisar guardar backups antigos, preserve a pasta .app/backups da instalação anterior.
  4. Não reaproveite o ambiente .app/venv nem copie logs e arquivos de dados de contas ou sessões para a nova instalação.
Avançado: recriar as dependências do aplicativo

Quando o ambiente Python da ferramenta estiver incompleto ou corrompido, abra o terminal na pasta extraída e execute o comando abaixo. Ele recria o ambiente de dependências e executa o setup novamente.

RECRIAR O AMBIENTE PYTHON
bash ".app/setup.sh" --recreate-venv --pause-on-exit

Confirme que você está na pasta da instalação que pretende reparar. Esse procedimento não é um roteiro de restauração de conversas.

SE UMA ETAPA NÃO FUNCIONAR

Encontre o próximo ajuste.

O setup não terminou

Confira a mensagem na janela de configuração e o arquivo .app/logs/setup-result.txt. Use uma pasta gravável pelo seu usuário e tente novamente depois de corrigir o requisito ausente.

EXECUTAR SETUP COM SAÍDA VISÍVEL
bash ".app/setup.sh" --pause-on-exit
O setup terminou, mas o Linker não abre

Confira se o projeto foi extraído inteiro e se o iniciador está junto da pasta .app. O log de abertura fica em .app/logs/session-linker-error.log. Remova dados sensíveis antes de compartilhar qualquer trecho para diagnóstico.

A conta de destino não aparece

Entre nessa conta no Claude Desktop do mesmo computador e abra Code ou Cowork pelo menos uma vez. Depois, feche o Claude e atualize a lista no Linker. A aba escolhida deve corresponder ao tipo de sessão que você quer usar.

A sessão vinculada não apareceu no Claude

Encerre completamente o Claude Desktop, reabra e entre na conta de destino correta. Confira também se você está olhando a aba Code ou Cowork correspondente à sessão.

Uso um perfil alternativo do Claude

O aplicativo reconhece perfis locais, incluindo Claude-3p. Para restringir a execução a uma raiz específica, consulte a seção de perfis no guia técnico do repositório.

Como pedir ajuda?

Informe macOS, a versão ou commit utilizado, Code ou Cowork e a etapa em que o problema ocorreu. Não envie transcripts, backups, credenciais, rótulos ou identificadores de contas à issue.
